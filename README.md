# Customer Shopping Behavior Analysis 

## Project Overview
This project analyzes customer shopping behavior using an end-to-end Data Analytics pipeline. The process involves extracting raw data, cleaning it using Python, loading it into a PostgreSQL database, running business queries, and visualizing the insights in an interactive dashboard.

## Tools & Technologies Used
* **Data Cleaning & ETL:** Python (Pandas, SQLAlchemy)
* **Database Management:** PostgreSQL
* **Data Analysis:** SQL (CTEs, Window Functions, Aggregations)
* **Data Visualization:** Power BI

## Repository Files
1. `Data_Preparation_Pandas.pdf`: Python script showcasing data cleaning and direct database loading.
2. `Shopping_Behavior_Queries.sql`: Advanced SQL queries answering critical business questions.
3. `Customer_Behavior_Dashboard.pbix`: The raw Power BI dashboard file.
4. `Dashboard_Screenshot.png`: Visual overview of the final interactive dashboard.

## Key Insights
* **Top Category:** Clothing generated the highest revenue and sales volume.
* **Customer Demographics:** The 'Young Adult' demographic drove the highest sales volume and revenue, closely followed by the 'Middle-aged' segment, indicating a strong market presence among buyers under 50.
* **Subscription Impact:** Non-subscribers make up 73% of the customer base, highlighting a massive area for targeted marketing and growth.
